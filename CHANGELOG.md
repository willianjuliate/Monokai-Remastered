# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Fixed
- Prevented Java's semantic type color from overriding the `var` keyword color.

- Updated documentation references to the new/legacy names for consistency.

### Added
- Added the dark and light theme variants under the Monokai Remastered naming.

## [0.0.1] - 2026-10-06

### Added
- Initial theme package with dark and light variants.
- Basic VS Code theme configuration and metadata.
