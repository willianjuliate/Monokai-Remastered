# Changelog

All notable changes to this project will be documented in this file.

## [0.0.8] - 2026-10-14

### Changed
- Updated the README and package metadata for the latest theme release.
- Swapped in the new icon asset for the extension branding.

## [0.0.7] - 2026-10-13

### Changed
- Updated the foreground colors across the dark and light themes for better readability.
- Refined Java imported type name styling in both themes.

## [0.0.5] - 2026-10-08

### Fixed
- Prevented Java's semantic type color from overriding the `var` keyword color.
- Refined Java semantic token colors for both themes to improve readability and consistency.

### Changed
- Updated the foreground color for primitive types in the Java token mappings.

## [0.0.4] - 2026-10-07

### Changed
- Updated the package icon reference to use the new `mr.png` asset.

## [0.0.3] - 2026-10-06

### Added
- Added the Monokai Remastered Light color theme and improved consistency with the dark variant.

## [0.0.2] - 2026-10-06

### Changed
- Renamed the extension and theme labels back to Monokai Remastered Dark & Light.
- Updated the display name and theme names to use the original branding.
- Renamed the theme files to match the Monokai Remastered naming convention.
- Updated documentation references to the new/legacy names for consistency.

### Added
- Added the dark and light theme variants under the Monokai Remastered naming.

## [0.0.1] - 2026-10-06

### Added
- Initial theme package with dark and light variants.
- Basic VS Code theme configuration and metadata.
